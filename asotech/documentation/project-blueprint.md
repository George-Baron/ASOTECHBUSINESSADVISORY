Develop ASOTECH Business Advisory into a professional, scalable and technology-driven consulting and software solutions company.

## 6.2 Inventory Ledger

The stock movement ledger must be the authoritative record of inventory transactions.

Every movement must capture:

- Product.
- Organisation.
- Quantity.
- Source location.
- Destination location.
- Transaction type.
- Transaction reference.
- User.
- Date and time.
- Approval state.
- Integration event reference.

Balances must be maintained consistently with the ledger.

## 6.3 Stocktaking Workflow

```text
Create Stock Count Session
          |
Select Organisation
          |
Select Warehouse / Locations
          |
Generate Count Sheets
          |
Assign Stock Counters
          |
Capture Physical Quantities
          |
Compare with System Snapshot
          |
Calculate Variances
          |
Investigate / Recount
          |
Reconciliation Review
          |
Approval
          |
Post Approved Adjustment
          |
Generate Final Report
```

The system must retain original count values and recount history.
